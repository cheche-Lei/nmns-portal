# NMNS Portal

**中文**：優化國立自然科學博物館活動報名平台和會員中心  
**英文**：Optimized event registration platform and member portal for National Museum of Natural Science

## 專案概述 / Project Overview

專案起源於準備國立自然科學博物館資訊職缺甄試，目標是 **提升會員報名活動與查看課程的使用體驗，並優化活動列表與行程安排流程**。

主要優化點包括：

### 1. 親友名單管理與多人報名
- **現況**：家長需為每位子女註冊帳號，並來回切換報名，無法總覽所有已報名課程  
- **優化**：會員可建立親友名單，一次性替多名家人報名，並集中管理所有報名紀錄  

### 2. 會員中心統整報名狀態
- **現況**：會員中心與報名系統分離，查看報名狀態需跳轉多個頁面  
- **優化**：整合會員中心，會員可一次性查看所有報名課程與活動  

### 3. 活動列表呈現優化
- **現況**：活動只能單一類別或身分查詢  
- **優化**：可同時使用多選篩選條件（類別 + 參加者身分），方便找到適合課程  

### 4. 收藏與行程規劃功能
- **現況**：每天有多場次活動，使用者難以安排順序  
- **優化**：可收藏感興趣活動，並透過會員中心行事曆安排行程
